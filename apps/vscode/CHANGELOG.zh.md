## 0.0.1 — 2026-10-11

- 无需打开 Desktop，即可通过原生输入框配置共享密钥、API 地址及默认模型；不会自动测试提供方。
- 标明共享/隔离模式并提供作用范围明确的恢复操作，保留历史及其他原生客户端租约。
- 按工作区内的会话子目录解析原生文件链接，验证共享 V3 到 V4 迁移且不重写前代。
- RC 线适配 DSH `0.2.0-rc.2`，扩展开发版本保持 `0.0.1`。
- 保留 Desktop 登录 shell 环境准备，在共享冷启动时传递所选运行时版本。
- 仅对新初始化的社区共享 profile 默认禁用产品分析；保留已有策略，并区分独立的反馈遥测。
- 使用共享主题 token，基于 RC 验证编辑器导航、工具分组及可跨平台回放的上下文录制。

- 添加社区身份标注、公开安装指引、隐私披露及包元数据。
- 将社区作者名及预定发布者设为 `LonelyQuantum`；扩展版本保持 `0.0.1`，并说明如何从本地预览身份迁移。
- 在打包流程中包含 PNG 图标、许可声明及 SHA-256 校验文件。
- 包含双语安全指南及社区仓库的私密漏洞报告渠道。
- 校验发布文件，并在检查 Marketplace 发布准备时拒绝本地发布者占位标识。

- Desktop 和 VS Code 均可初始化并启动共享后端，无需先打开 Desktop。
- 保持每个 home 仅有一个后端，在冷重启和崩溃恢复后保留共享提供方配置及持久化对话。
- 将显式隔离模式和 Desktop 专属 Office/Python 资源与扩展核心运行时区分开。

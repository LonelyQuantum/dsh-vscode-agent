# 隐私与数据处理

[English](PRIVACY.md) | 中文

本说明介绍社区扩展及默认打包的 DSH 配置。自定义提供方、Cordis 插件、MCP 服务器和用户配置可能改变网络活动及数据访问范围，各运营方有自己的政策。此扩展不是由 DeepSeek 或 OpenAI 运营的服务。

## 本地存储与访问

共享模式使用所选 Harness home 中的密钥、提供方设置和持久化对话数据，不会将提供方密钥复制到 VS Code 设置或 Webview。原生配置将密码输入框中的值直接发送给经过认证的后台凭据 API；设置读取只返回凭据状态，不返回已保存密钥。保存配置不会测试提供方或发送模型请求。隔离模式将配置的密钥存入 VS Code SecretStorage，并在扩展全局存储中保存按工作区隔离的配置数据。卸载扩展不会删除共享 Harness home 或提供方保存的记录。

对话日志和附件可能包含源代码、本地路径、工具输出及其他敏感内容。请将 Harness home 及其备份视为私有数据。共享访问面向同一操作系统账户下运行的可信应用，不面向不受信任的本地用户或远程客户端。

## 模型请求与工具

发送提示词时，消息、所选编辑器上下文、附件、工具结果及组装后的 agent（智能体）上下文可能发送给配置的模型提供方。仅捕获选中文字或 Problems 不会发送模型请求；提交消息时会包含捕获的快照。工具和已安装插件可以根据配置及权限访问文件、执行命令或联系外部服务。维护者无法控制提供方的数据保留，也不能保证插件会对私有数据进行脱敏。

<a id="optional-deepseek-searchfetch"></a>
### 可选 DeepSeek Search/Fetch

组合中的提供方已注册，但默认未被选用。在共享的 Web 搜索设置中启用**使用新的 Web Search API**会同时选择两者。Search 发送搜索词，Fetch 发送请求的 URL。两者的 API 基地址默认为 `https://api.deepseek.com/v1/tools`，独立于模型地址。Search 在 `sendOriginalQuestion` 开启时，还会发送最新一条人类消息折叠空白后截取的前 128 个字符；该项默认开启，消息可能包含粘贴或附加的上下文。在共享提供方配置中关闭该字段即可不发送问题。认证使用配置的凭据引用或账户授权，密钥不进入 Webview。检索计费独立于模型 token 统计。详见[提供方配置](../../packages/web/web-deepseek-api/README.zh.md)。

## 产品分析

任一社区客户端初始化的新共享主目录均禁用产品分析。已有 profile 保留其策略，包括已开启的上游默认值；连接本扩展不会禁用已有后端的采集。启用时，Desktop 交互及 Host 上下文压缩事件可能发送到 DeepSeek 产品收集服务，与会话反馈独立。[产品策略](../../packages/client/product-analytics/README.zh.md)列出字段及触发时机。`DSH_TELEMETRY_DISABLED` 不禁用此产品导出器；应修改 profile 的 `product-analytics` 配置。模型请求和工具联网不受影响。

## 反馈共享

打包的 DSH 配置默认采用仅反馈触发的 Session 遥测。新的显式反馈、评分、编辑或撤回操作可能授权上传截至该反馈的对话前缀，包括上下文、工具参数和结果、本地工作目录路径及匿名 home 标识。默认接收方是 DeepSeek 的 Harness 遥测收集服务，配置部署时可选择其他地址。仅发生普通模型活动不会授权此反馈上传。提供方 API 密钥不属于 Session 事件，但粘贴到提示词中或由工具输出的秘密可能包含在上传内容中。

底层配置支持在后端启动前将 `DSH_TELEMETRY_DISABLED` 设置为非空值，以禁用此遥测。无论哪个客户端之后连接，运行中的共享后端都会保留启动时的配置；改变启动环境前请关闭两个客户端。禁用遥测不会禁用模型请求、工具联网或提供方的数据保留。详见[上游遥测行为](../../packages/session/session-telemetry-otel/README.zh.md)。撤回反馈不等于要求删除此前上传的记录。

## 支持与披露

社区问题跟踪器是公开的，请勿附加原始日志、home 目录或密钥。普通扩展问题可通过[问题跟踪器](https://github.com/LonelyQuantum/dsh-vscode-agent/issues)提交脱敏后的复现步骤。请按[社区安全策略](SECURITY.zh.md)私密报告漏洞，不要公开利用细节或私有数据。
